## Independent evidence

`audit.py` imports no predecessor verifier, compiler, interpreter or producer.
It reads the actual selected labels and matching, independently reconstructs
the canonical binary charts and expected operators, and checks **all 280
generated recipes on all 512 basis columns: 143,360 exact Gaussian columns**.
The source checks all recipe signed-Pauli images plus a global-phase column,
which already establishes the intended full operators. This review adds a
separate implementation and complete explicit-column evidence, rather than
claiming its source proof was incomplete.

The expected-column oracle uses Gaussian integer pairs and powers of two.
It independently propagates the zero column and conjugated X generators.
For `U X_x U^-1 = i^p X_a Z_b`, its column is obtained by multiplying the
zero-column coefficient at y by `i^(p+2*b.y)` and moving it to `y+a`.
This follows from `|x> = X_x|0>` and fixes the global phase. Actual recipe
columns are instead expanded analytically from their monomial tables and
positive child coefficients, products of `(1+i)/2` or `(1-i)/2`. The two
routes agree entry for entry without floating-point arithmetic.

The separate literal block interpreter checks all four independent public
arrays, arbitrary target dirt, source restoration, exact frames and two
owned-copy lifetimes. No public dirt is erased. Private copies may be
nonzero when disposed under the inherited owned-copy contract; this is not
reversible cleanup. Multiplying the block invoice by all 56 matched planes
gives 224 public input arrays, 112 private lifetimes and one private array at
peak. Both source-entry and target-exit adapters are checked; the rank-zero
adapter recipes remain explicit, and their physical implementation is not
priced as free.

Five controls reject wrong native global phase, a one-direction drop, a
missing second payload, a shared broadcast substituted for the identity and
a half-counted invoice. A legal one-payload broadcast is separately accepted
for its actual rank-one endpoint. This distinguishes sharing a payload from
delivering two independent ones.

## Exact source replay

The seven files in `source/` are unchanged Git bytes from PR2203, with all
SHA-256 and Git-blob pins in `PREDECESSORS.json`. The four original runtime
inputs remain pinned in `SOURCES.json`. `RECIPES.json` is regenerated by
observing the original main function's return with Python's profile callback,
without editing any source or replacing a source callable. Its complete
canonical digest equals the original expected receipt.

`replay_source.py` copies the authenticated original package and inputs into
a fresh export, runs the original primary and export/integrity commands, and
compares every generated recipe and receipt field. Each direct replay gets a
new empty Python bytecode namespace; the original legacy loader is unchanged.
This controls cache selection for the observed run and is not a claim that
the predecessor's loader is hardened in every external environment. The copied export itself is checked against all eleven SHA-256 and Git-blob
pins before either child runs; all exported source bytes must remain unchanged. The profiler is only an
observation mechanism; it is not the independent mathematical oracle.

The review also executed the source's original registered runner on native
Windows CPython 3.12.7. Its metadata requires historical Git objects, so the
export was supplied the existing repository object store for that check.
A pure Git-free registered attempt stopped at this metadata requirement;
the source's direct export tests and this package's source replay are
Git-free. Neither result is misreported as a scientific failure.

## Proof and scope assessment

Within each independently implemented block, scalar one-array totals factor
the required two-by-two identity transfer through a message space. Rank two
requires two independent totals. Equivalently, for payload dimension d,
the required map has rank 2d and one full array has dimension d. Each total
has the complete nondegenerate source/reader plane, so the inherited
one-total tariff charges rank two; the construction attains four per block.
These are the source's conditional premises, not a proof for all conceivable
physical decoders. Independent-block floors cannot be summed after allowing
arbitrary cross-plane sharing. The changed plane entrance is also essential:
the old line entrance needs a separately paid rank-one adapter per port.

The cost rejection grants the proposed two-unpaid coverage law and ideal
hosting. For every `0<r<m` and `a>=0`, `(r/m)^(1-a) >= r/m`; hence failure at
zero saving excludes positive saving inside that model before extra costs.
Global routes, backward orientation, chronological ownership, payload-depth
implementation, precision/tape and selected cold replay remain outside this
finite review. The output is supplemental independent evidence, not a
maintainer merge decision, human review or formal-kernel theorem.
